"unused_files.xlsx" is the (manually processed) output of "scripts\archive\find_unused_files.R", and it contains files that were moved to archive folders during the archiving process of folders and sub-folders in the root "DCC-v3" folder, since they are not in use anymore. It has a documentation of the original location of the files and where they were archived.

2. "archiving_files_that_were_created_in_archived_scripts.xlsx" is the (manually processed) output of "scripts\archive\get_files_and_their_mentions.R", and it contains files that weren't in an archived folder / sub-folder. but they were mentioned in a code file (R / qmd) that *was* already archived. These files were archived as well, with a documentation of the original location of the files and where they were archived. Note: the xlsx file also contains archived files that were mentioned in code files that *weren't* archived, and these haven't been moved.
